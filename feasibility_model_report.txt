Design note: optimized for infeasible-class recall over raw accuracy, since a missed
'this schedule is unrealistic' warning is more costly than a false alarm. An earlier
version of this script used accuracy + a default 0.5 threshold and caught only ~13-18%
of genuinely infeasible schedules; this version explicitly tunes the threshold against
that failure.
